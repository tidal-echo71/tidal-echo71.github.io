领域概览：人物关系与空间设定

OVERVIEW / 01

鸠摩智的出场身份是吐蕃国师，武功高、地位显、口才锋利。约见高冷美少女这一设定把这三点同时压到一张茶桌上：国师身份能换来递帖入座的资格，却换不来对方多说一句。美少女的沉默成为推进器，所有冲突都在她点头、侧身、放下茶盏这些动作里发生。

条目收录标准相对明确：必须写清递帖人、候见地点、入座朝向、告辞时留下的那句话。四项缺一项不进入主列表，只作草稿归档。11月2日截取时，主列表共46条，草稿区19条，草稿中三分之一是因为“告辞未留问句”被退回。

深度解析：沉默如何承担叙事推进

ANALYSIS / 05

一个可被反驳的判断：高冷美少女的沉默不是性格标签，而是信息控制手段。她每少说一句话，鸠摩智就得多解释一层，而解释的内容恰好暴露他的来意。这条判断若成立，沉默应与场景私密程度正相关；若不成立，沉默应随对话轮次均匀分布。现有条目支持前者。

案例时间线：两次截取之间多出的两轮问答

10月26日截取的「茶肆候见」版本 v2.1 共七轮问答，11月2日版本 v2.4 增至九轮。多出的两轮全部发生在入座后的第三盏茶时段，内容分别为追问师承与询问风物来历。候见阶段没有新增轮次。这说明扩充集中在私密程度更高的入座段，而非等待段。

可核对项：v2.1 文件记录七轮，v2.4 文件记录九轮；多出的两轮时间戳均在入座后第18分钟与第26分钟。说法差异来自两次截取时的章节划分不同，v2.4 把原本合并的问答拆开计数。

数据对比：短句长度与对话轮次的反向关系

把十一个短句按字数排列，五字以下六句，六至九字五句。字数越少，其后紧跟的鸠摩智发言越长。最短的“茶凉了”三字之后，紧接着是一段一百二十七字的武学评述。反向关系在九个条目里重复出现七次，剩余两次是美少女主动开启新话题，属例外。

规则前后变化：递帖措辞的删改

旧版递帖写“久仰高名，特来求见”，新版只留“求见”二字。改动理由写在 v2.3 修订注里：久仰暗示双方已有了解，与后文美少女初见时的陌生反应冲突。删去之后，候见阶段从一轮寒暄压缩为零轮，入座直接进入武学话题。这一改动让全篇节奏提前约四十分钟。

推论随之成立：递帖字数与候见时长负相关。帖面越简，等待越短。现有四条对照记录里，三字帖平均候见两盏茶，八字帖平均三盏半。样本量小，结论暂列推测层，需等收录到十条以上再做判断。

  • 转述有读者转述称“美少女全程未正眼看国师”，原文实为两次正眼、三次侧视，转述有偏差。

体验指南：四步走完一次约见

GUIDE / 06
  1. 递帖。随从持帖至门廊，帖面只写求见二字，右手递出，退三步站定。时间约两分钟，不宜寒暄。
  2. 候见。在门廊等候两盏茶，约四十分钟。观察门帘厚度与灯笼位置，判断内部是否有人交谈。
  3. 入座。背窗者先开口。先谈武学，再谈风物，比例约五比二。短句回应时不要抢话。
  4. 告辞。起身后留一句未答之问，不求解。走出月洞门时侧身让路，视线不交叠。

四步时间比例约为 1:2:5:2。候见与告辞合计不足全程三成，入座段是主体。

常见问答：设定、流程与版本核对

FAQ / 08
鸠摩智约高冷美少女的设定核心是什么？
核心在于身份反差与对话张力。鸠摩智以吐蕃国师身份出现，武学修为与世俗阅历形成压迫感；高冷美少女以沉默和短句回应，双方在信息不对称中推进关系。设定不依赖外貌描写，靠称谓、礼仪与试探性提问建立层次。
高冷美少女为什么在第二次见面才开口？
第一次见面她只以点头和侧身回应，第二次在茶肆才说出完整句子。原因是场景从开阔街市转入半封闭空间，人物需要观察对方是否携带随从。开口时间点与空间私密程度相关，与情绪无关。
鸠摩智约见流程包含哪些步骤？
流程分四步：递帖、候见、入座、告辞。递帖由随从完成，候见在门廊进行，入座后先谈武学再谈风物，告辞时留一句未答之问。四步时间比例约为1比2比5比2。
场景构建中哪些细节容易被忽略？
茶肆座位的朝向、门帘厚度、随从站位这三项常被忽略。座位朝向决定谁背光，门帘厚度影响对话音量，随从站位决定插话时机。三项都影响对话节奏。
条目更新频率与版本差异如何核对？
条目按周更新，版本号标注在列表右侧。核对方式为对比同一章节的两次截取时间，差异集中在对话轮次与场景描写。11月2日版本比10月26日版本多出两轮问答。
